# 📘 CSS Fundamental & Sejarah

![image](https://cdn.freebiesupply.com/logos/large/2x/css3-logo-png-transparent.png)

CSS (Cascading Style Sheets) diusulkan oleh Håkon Wium Lie pada 10 Oktober 1994 saat bekerja di CERN bersama Tim Berners-Lee. Tujuannya adalah memisahkan struktur konten (HTML) dari tampilan (desain). W3C merilis CSS1 (1996), CSS2 (1998), dan CSS3 (2011) yang membawa revolusi desain web modern seperti animasi dan responsivitas.
